# Coders of Delhi — Data Science Project

## 📌 About

This project is a practical implementation of concepts covered in the **Data Science Handbook**. It focuses on analyzing and extracting insights from the **Coders of Delhi** dataset using Python and Data Science libraries.

## 🛠️ Tech Stack

* Python
* NumPy
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

## 🔄 Workflow


Dataset
   ↓
Data Loading
   ↓
Data Cleaning
   ↓
Data Preprocessing
   ↓
Exploratory Data Analysis
   ↓
Data Visualization
   ↓
Insights


## 📚 Concepts Used

* Python for Data Science
* NumPy
* Pandas
* Data Cleaning
* Data Preprocessing
* Exploratory Data Analysis (EDA)
* Statistics
* Data Visualization

## 🎯 Objective

To apply the Data Science concepts learned from the handbook to a real dataset and derive meaningful insights through data analysis and visualization.
